# Pooltoys Mod

Pooltoys for Minecraft!

## About

This is a simple mod that adds inflatable pooltoys to Minecraft!
You can ride them like boats, relax on them in your pool, anything you want!

They don't mind!

## Features

- Squirky Bumping When Touched
- Easy Crafting Recipe (any wooden boat with glass pane inside)
- Recipe Book Support
- Secret names?????
